### Photography Portfolio Website

https://www.shamusosler.ca

This app is using [photo-site-api](https://github.com/Shamoosey/photo-site-api) to handle database functionality. See more info in the API project repo for running it.

Use `npm run dev` to start up the UI.

env variables for local development

```
VITE_API_BASE_URL=http://localhost:3000
VITE_CLERK_PUBLISHABLE_KEY=
```
